DEFENDER OCTA — DEMO MODE WIRING GUIDE
=======================================
Three files to edit. Do them in order, then restart Flask.


---------------------------------------------------------------
STEP 1 — site_config.json
---------------------------------------------------------------
Add a "demo" block anywhere at the top level (e.g. after "backup"):

  "demo": {
    "demo_mode": false,
    "_comment": "true = seeded DEMO rows are counted in charts and KPIs. Set false before any real deployment."
  }

Remember the comma after the preceding block.


---------------------------------------------------------------
STEP 2 — site_config.py
---------------------------------------------------------------
(a) In _DEFAULTS, add one line after the "backup" entry:

    "demo":   {"demo_mode": False},

(b) In _Config.__init__, after the Backup section, add:

        # Demo mode
        self.demo_mode = bool(cfg["demo"]["demo_mode"])

(c) In warn_if_insecure(), add this before the `if warnings:` line:

            warnings.append(

STEP 3 — db.py
---------------------------------------------------------------
(a) Near the top, after the DB_PATH line, add:

    # Demo rows use plates prefixed "DEMO". When demo mode is off they
    # are excluded from every aggregate query.
    def _demo_filter() -> str:
        """Returns a SQL fragment to append to a WHERE clause."""
        try:
            from site_config import CONFIG
            if CONFIG.demo_mode:
                return ""            # count everything
        except Exception:
            pass
        return " AND plate NOT LIKE 'DEMO%'"


(b) Now add the filter to each aggregate query. In every function below,
    find the WHERE clause and append {_demo_filter()} inside the f-string.
    The queries must become f-strings (note the f prefix).

---------------------------------------------------------------
DAILY USE
---------------------------------------------------------------
Seed demo traffic (once; it persists):
    python seed_demo.py            # today only
    python seed_demo.py --days 7   # a week of history for the calendar

Turn demo data ON for a recording:
    site_config.json  ->  "demo_mode": true    ->  restart Flask

Turn it OFF for real use:
    site_config.json  ->  "demo_mode": false   ->  restart Flask
    (rows stay in the database but are excluded from every query)

Remove demo rows entirely:
    python seed_demo.py --clear


---------------------------------------------------------------
WHAT THIS DOES NOT COVER
---------------------------------------------------------------
- Incidents are stored in a separate table and are not seeded or
  filtered. Demo incidents (if any) must be managed manually.
- The live KPI counters (vehicle_stats) are rebuilt at startup from
  rebuild_today_state(), so they honour demo_mode. But events
  recorded WHILE the server runs always count, demo mode or not.
- The committee PDF reads the same filtered functions, so it will
  correctly exclude demo rows when demo_mode is false.
